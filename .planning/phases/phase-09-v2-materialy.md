# Phase 9 — Materiały V2 (Hiring Manager + Excalidraw)

## Cel
Przygotować się do Etapu V2: pytania behawioralne (STAR) i szkice Excalidraw.

## Zależności
Brak (można równolegle z Phase 8).

## Część A — Hiring Manager (STAR)
Przygotuj historie metodą STAR (Situation–Task–Action–Result) dla:
1. Konflikt / trudny klient lub stakeholder.
2. Niejednoznaczny problem → jak go zdekomponowałeś (bez pełnych danych).
3. Błąd produkcyjny pod presją czasu.
4. Współpraca z zespołem, który nie zgadza się z Twoim rozwiązaniem.
5. Wdrożenie złożonego systemu (przełożenie techniki na wartość biznesową).

Każda historia: 1–2 min, konkretne liczby/twarde rezultaty. Użyj `presentation/02_tok_myslenia_v1.md` jako punktu startu (jsou tam odpowiedzi na trudne pytania).

## Część B — Excalidraw (wireframing)
Przećwicz ręcznie w Excalidraw (tylko prostokąty + tekst, zgodnie z `presentation/06_v2_excalidraw.md`):
1. **Szkic 1:** Wireframe rozmowy głosowej (gość → Anna → narzędzia → potwierdzenie).
2. **Szkic 2:** Widget webowy (floating button, transkrypcja, chips, success card).
3. **Szkic 3 (opcjonalnie):** System design (diagram integracji LLM ↔ chmura ↔ PMS/SMS).

Ma być TYPOWO szkicowo — nie perfekcyjnie. Cel: pokazać myślenie na głos, nie gotowy produkt.
